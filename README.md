# 🧹 Projet Nettoyage IA

Un assistant de nettoyage de système intelligent propulsé par l'API Gemini. Tapez une requête en langage naturel, et l'IA se charge d'analyser et d'exécuter les actions nécessaires en toute sécurité sur votre machine.

## 🚀 Fonctionnalités

* **Interface en langage naturel :** Demandez simplement ce que vous souhaitez nettoyer ou organiser.
* **Sécurité intégrée :** L'IA renvoie soit du texte explicatif, soit du code ciblé. Le programme analyse et n'exécute que les commandes strictement autorisées pour éviter d'endommager votre système.
* **Fichier unique :** Tout le projet repose sur un script Python principal pour un déploiement et une lecture simplifiés.
* **Configuration sécurisée :** Les clés d'API et paramètres sensibles sont isolés localement dans un fichier `config.json`.
